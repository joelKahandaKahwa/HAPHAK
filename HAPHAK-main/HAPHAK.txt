Agis comme un développeur Full-Stack senior spécialisé en applications web sécurisées, modernes et responsives.

Je veux créer une application web complète destinée à gérer les inscriptions des participants à une retraite chrétienne.

IMPORTANT :
- Les participants doivent pouvoir accéder au formulaire depuis leur téléphone ou ordinateur, où qu'ils se trouvent.
- Ils ne seront pas forcément connectés au même réseau Wi-Fi que l'administrateur.
- Les données doivent être enregistrées dans une base de données contrôlée par l'administrateur.
- Ne pas utiliser Google Forms, Google Sheets, Firebase, Supabase ou une autre solution cloud pour stocker les données.
- L'application doit pouvoir être développée et testée entièrement en local.
- Elle devra ensuite pouvoir être déployée sur un serveur Internet.
- Le système doit être conçu pour que les données des participants restent dans la base de données de l'application/serveur que je contrôle.
- envoyer automatiquement un mail a la personne qui viens de s'inscrire, un mail contenant un code qr que l'admi va scanner a l'entree pour reconnaitre la personne.

6. ENVOI DES DONNÉES
==================================================

"CONFIRMER MON INSCRIPTION"

Le frontend doit envoyer les données à une API REST.

Exemple :

POST /api/registrations

Le serveur doit :

1. Recevoir les données
2. Les valider
3. Nettoyer les données
4. Les enregistrer dans SQLite
5. Générer un identifiant unique d'inscription
6. Retourner une réponse JSON

Exemple :

{
  "success": true,
  "registrationId": "RET-2026-0001"
}
